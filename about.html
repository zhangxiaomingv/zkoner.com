关于优引GEO系统

我们做一件事：让品牌的 AI 可见性可度量、可优化、可验证。

产品定位

优引GEO系统是品牌 AI 可见性的诊断与监测平台。它不承诺“保证排名”，而是把 AI 引擎对品牌的真实认知用结构化报告呈现：哪里被收录、哪里是幻觉、哪里是负面，下一步该做什么。

技术栈

  • 控制台：纯静态 HTML/CSS/JS，零外部依赖，可离线演示。
  • 监测管线：Node.js 脚本，调用豆包与 DeepSeek 真实 API 多轮采样。
  • 调度：n8n 工作流按日自动运行，支持手动触发。
  • 数据：JSON 文件本地存储，按天去重，客户可完全掌控。

数据与安全

系统采用 BYOK（Bring Your Own Key）设计：API 密钥由客户提供，只存放在客户本机的 data/config.json 或环境变量中，不进入 Git、不上传第三方服务器。监测结果同样只落在本地 data 目录。

交付方式

  1. 演示试用：直接打开控制台，体验诊断与示例报告。
  2. 本地部署：交付 scripts + data 包，客户配置自己的 API Key 后运行。
  3. 陪跑服务：诊断 → 内容修复 → 信源铺设 → 每日复测 → 月度复盘。
